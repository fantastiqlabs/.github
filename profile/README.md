## What we make

We build browser games, music and event tools, and practical software for creative work. Our projects range from playful experiments to tools we use every day.

### Open source

- [Logtastiq](https://github.com/fantastiqlabs/logtastiq) — Turn Warcraft Logs into clear next steps.
- [Fantastiq Bingo TBC](https://github.com/fantastiqlabs/fantastiq-bingo-tbc) — a raid bingo add-on for World of Warcraft: The Burning Crusade Classic Anniversary.

### In development

- **Guildtastiq** — Everything your guild needs, in one place. The public release is in preparation.

## Build with us

We welcome clear bug reports, practical ideas, and focused contributions. Check a project's README before you open an issue. It explains the current scope and the best place to start.

For project documentation, visit [Doctastiq](https://doctastiq.fantastiq.net). More projects are in development.
